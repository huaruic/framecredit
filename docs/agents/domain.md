# Domain Docs

FrameCredit uses a single project context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.
- If either location does not exist, proceed without treating its absence as a blocker.

## Vocabulary

Use terms as defined in `CONTEXT.md`. Avoid drifting to synonyms that the glossary explicitly rejects.

## Architectural decisions

If proposed work conflicts with an existing ADR, identify the conflict explicitly rather than silently overriding it.
